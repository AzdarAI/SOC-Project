Modul 01

Struktur HTML

HTML (HyperText Markup Language) adalah tulang punggung setiap halaman web. Setiap dokumen HTML memiliki hierarki elemen yang terstruktur.

Anatomi Dokumen HTML

<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8"/>
<title>Judul</title>
</head>
<body>
<header>
<h1>Judul Utama</h1>
</header>
<main>
<section>
<p>Konten...</p>
</section>
</main>
<footer></footer>
</body>
</html>

Elemen Semantik HTML5

<header> Kepala halaman / bagian
<nav> Navigasi utama
<main> Konten utama halaman
<section> Pengelompokan konten
<article> Konten mandiri (artikel)
<aside> Konten sampingan
<footer> Kaki halaman / bagian
<figure> Konten ilustrasi / media

Modul 04

Hyperlink

Tag <a> membuat tautan ke halaman lain, berkas, atau lokasi dalam halaman yang sama. Berbagai atribut mengubah perilaku tautan.

Jenis-Jenis Hyperlink

🔗 Link Eksternal (target=_blank) ⚓ Anchor Link (ke atas) ✉️ Mailto Link 📞 Tel Link Kunjungi MDN → W3Schools

Atribut Hyperlink

<!-- Link eksternal di tab baru --> <a href="https://example.com" target="_blank" rel="noopener noreferrer"> Buka di Tab Baru </a> <!-- Anchor: lompat ke section tertentu --> <a href="#bagian-tertentu">Ke Bagian Ini</a> <section id="bagian-tertentu">...</section> <!-- Download file --> <a href="file.pdf" download="nama-file.pdf">⬇ Download PDF</a> <!-- Kirim email --> <a href="mailto:user@email.com?subject=Halo">Kirim Email</a>

Frame & IFrame

Kode IFrame

Kode Custom Cursor (JS + CSS)

/* CSS — Sembunyikan cursor asli */ body { cursor: none; } /* Elemen cursor kustom */ #cursor-dot { width:8px; height:8px; background:#4fffb0; position:fixed; border-radius:50%; pointer-events:none; } #cursor-ring { width:36px; height:36px; border:2px solid #4fffb0; position:fixed; border-radius:50%; pointer-events:none; } /* JavaScript — Ikuti posisi mouse */ const dot = document.getElementById('cursor-dot'); const ring = document.getElementById('cursor-ring'); document.addEventListener('mousemove', (e) => { dot.style.left = e.clientX - 4 + 'px'; dot.style.top = e.clientY - 4 + 'px'; ring.style.left = e.clientX - 18 + 'px'; ring.style.top = e.clientY - 18 + 'px'; });
